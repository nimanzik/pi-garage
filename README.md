# pi-garage

Nima's personal collection of packages for the [Pi Coding Agent](https://pi.dev/).
Install only the ones you want.

## Packages

| Package                                                             | Description                                                                      |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| [@nimanzik/pi-prompt-mode](extensions/pi-prompt-mode/README.md)     | Switches model and thinking presets in the prompt editor.                        |
| [@nimanzik/pi-auto-title](extensions/pi-auto-title/README.md)       | Names Pi sessions from their first request.                                      |
| [@nimanzik/pi-prompt-polish](extensions/pi-prompt-polish/README.md) | Rewrite a draft prompt using recent conversation, then review it before sending. |
